# Lilium Species Registry

Status: **Canonical Lilium species authority; no assignments**

This registry owns species-level botanical identities inside Lilium. The
[Garden Genus Registry](../../registry/genera.md) owns the *Lilium* genus assignment.

No canonical species-to-internal-identity mapping is currently established. A future assignment
must identify a durable Lilium concept, preserve accepted taxonomy, and provide clearer semantic
value than an ordinary technical name.
