# Flora Species Registry

Status: **Not applicable**

Flora is a deliberate exception to Garden's genus-to-product convention. *Flora* is a collective
botanical term rather than a genus, so it has no taxonomically valid product species namespace.

The [Garden Genus Registry](../../registry/genera.md) owns this exception. Flora must use ordinary
domain naming for commands, plugins, hosts, and capabilities unless Garden later accepts a
different explicit botanical model.
