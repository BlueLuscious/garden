# Garden

Garden is an ecosystem of independent software products connected through explicit integration
boundaries, shared architectural values, and a botanical naming model.

The English architecture book begins at [docs/en/index.md](docs/en/index.md). It documents Garden
as an ecosystem without replacing the implementation, API, workflow, or release documentation
owned by each product repository.
